# Haive Fitness Centre

A responsive website concept for Haive Fitness Centre in Thiruvananthapuram, presenting the gym, services, trainers, gallery, memberships, and contact information through a premium fitness-focused interface.

## What it is for

The project is a polished business website prototype designed to give a fitness centre a modern digital presence and a clear path for visitors to explore services and memberships.

## Highlights

- Responsive landing page
- About, services, trainers, gallery, memberships, and contact sections
- Mobile navigation
- Animated splash/loading experience
- Modern dark visual design

## Tech stack

- HTML5
- CSS3
- JavaScript
- Font Awesome
- Google Fonts

## Run locally

Serve the project with any static web server. For example:

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000`.
